# inseme_tech

## Decription

INSEME TECH brings students together to build a strong, lasting community beyond the classroom. Through social events, tech workshops, robotics, and talks with professionals, we make technology accessible, encourage curiosity, and create connections that grow with every new generation.

## Hosting and data

- **Website hosting:** Netlify.
- **Database and backend services:** Supabase.

Deployment configuration and Supabase schema should be added once the application framework and data requirements are defined. Keep Supabase secret or service-role credentials out of browser code and commit only environment variable names, not secret values.
